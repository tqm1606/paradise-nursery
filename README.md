# Paradise Nursery

Paradise Nursery is a responsive online houseplant shop built with React and Redux Toolkit. Browse three plant collections, add plants to a cart, adjust quantities, remove items, and see your subtotal update immediately.

## Run locally

1. Install Node.js.
2. Run `npm install` in this directory.
3. Run `npm run dev` and open the local URL printed by Vite.

## Project structure

- `src/App.jsx` — landing page and view navigation
- `src/App.css` — landing page background and application styles
- `src/components/AboutUs.jsx` — company story
- `src/components/ProductList.jsx` — categorized plant catalogue
- `src/components/CartItem.jsx` — shopping cart and checkout message
- `src/store/CartSlice.jsx` — Redux cart state and actions

Plant photography is loaded from Unsplash. Checkout is a demonstration and displays a “Coming soon” message.
